# Pinta Pinta

App para pintar pensada para bebés. Se instala en el iPad desde Safari: Compartir → Agregar a inicio.

- Dibujos: adaptados de [Noto Emoji](https://github.com/googlefonts/noto-emoji) de Google (Apache 2.0).
- Música: canciones tradicionales tocadas con los instrumentos de FluidR3 GM (CC BY 3.0).
